# 给官网绑定自己的域名

站点现在在：`https://pl514.github.io/myriad-isle-web/`
绑定后可用：`https://<你的域名>/`（推荐同时开 `www`）

## 一、先买域名（你来做，约 ¥30–70/年）

任选一家，国内/国外都行：

| 平台 | 特点 |
| --- | --- |
| Cloudflare Registrar | 成本价、无溢价，需要信用卡，DNS 也在这里最好办 |
| 阿里云 / 腾讯云 | 支付宝付款方便，国内访问稳，需实名 |
| Namecheap / Porkbun | 便宜，支持支付宝（Porkbun） |

含义上建议：`myriadisle.com` / `myriadisle.cn` / `wandaodao.com` 这类，短、好记、能拼。

## 二、加 DNS 记录（在你买域名的地方操作）

到域名的 DNS 解析页，加这几条：

| 类型 | 名称 | 值 | 说明 |
| --- | --- | --- | --- |
| CNAME | `www` | `pl514.github.io` | 带 www 的地址 |
| A | `@` | `185.199.108.153` | 顶级域名（GitHub 官方 IP） |
| A | `@` | `185.199.109.153` | 同上 |
| A | `@` | `185.199.110.153` | 同上 |
| A | `@` | `185.199.111.153` | 同上 |

> 如果 DNS 服务商支持 `ALIAS`/`ANAME`（Cloudflare 叫 CNAME flattening），顶级域名也可以直接 CNAME 到 `pl514.github.io`。

## 三、告诉 GitHub 这个域名

两种方式，任选其一：

**方式 A：仓库里放 CNAME 文件（推荐，可版本管理）**

在 `myriad-isle-web` 仓库根目录建一个 `CNAME` 文件，内容就是域名（不带 https、不带斜杠）：

```
www.myriadisle.com
```

推送后 GitHub Pages 会自动读取。

**方式 B：网页设置**

仓库 → Settings → Pages → Custom domain → 填域名 → Save。

## 四、开 HTTPS

Settings → Pages → 勾选 **Enforce HTTPS**。
GitHub 会自动签发证书，DNS 生效后几分钟到几小时可用。

## 五、验证

```powershell
# 看解析是否生效
nslookup www.myriadisle.com
# 看 HTTPS 是否正常
curl.exe -I https://www.myriadisle.com
```

应返回 `HTTP/2 200`。

## 常见问题

**打不开 / 404**
- DNS 还没生效（等 10 分钟到数小时）
- CNAME 文件里写了 `https://` 或结尾斜杠 —— 只能写裸域名
- 仓库 Settings → Pages 里还没填域名

**证书一直 pending**
- 先把 Custom domain 取消再重新保存一次
- 确认没有同时开 CDN 代理把验证挡住（Cloudflare 橙色云朵先关掉）

**国内访问慢**
- `*.github.io` 和部分 GitHub IP 在国内不稳定，介意的话可以套一层 Cloudflare（免费）或换国内静态托管（需要备案）。
